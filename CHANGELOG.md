# Changelog

## 2026-09-11

- Добавлена проверка сессии, отзыв сессий и обязательная смена стандартного пароля.
- Все операции изменения переведены на POST с CSRF-защитой и строгой валидацией.
- Выдача, возврат, отклонение и архивирование выполняются транзакционно.
- Устранены обход статуса через редактирование и изменение базы при GET-просмотре.
- Добавлен безопасный двухэтапный Excel-импорт с лимитами, проверкой дублей и кабинетами 408/411.
- Акты перенесены в закрытое хранилище и защищены проверкой владельца.
- PhpSpreadsheet обновлён до 5.9.0; Composer audit не находит известных уязвимостей.
- Добавлены повторяемые миграции, регрессионный тест и инструкция развёртывания.

## 2026-06-02

- Добавлен общий конфиг `config/app.php` с `BASE_URL`, `BASE_PATH` и timezone.
- Добавлены helper-функции для URL, редиректов, экранирования вывода, статусов и журнала действий.
- Добавлена таблица `activity_logs` и логирование ключевых действий.
- Добавлено поле `barcode` для оборудования.
- Добавлен быстрый поиск оборудования по штрихкоду.
- Добавлен JSON-эндпоинт `equipment/lookup.php` для поиска оборудования сканером.
- Добавлена выдача оборудования по заявке через сканирование на странице заявки.
- Добавлена страница возврата оборудования через сканирование.
- Обновлен dashboard администратора: статистика, последние заявки, последние действия.
- Исправлены статусы заявок: выдача использует `issued`, возврат использует `returned`.
- Исправлены записи `request_equipment`: теперь фиксируются `issued_at`, `returned_at`, `status`.
- Добавлена серверная валидация даты и времени в формах заявок.
- Исправлены и унифицированы редиректы через `BASE_URL`.
- Добавлены `database/schema.sql` и `database/migrations/final_update.sql`.
- Обновлена документация по запуску, миграции и проверке USB-сканера.
