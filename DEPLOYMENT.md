# Быстрый выпуск на хостинг

Минимальный порядок действий для первого боевого запуска.

## 1. Файлы

Загрузите на хостинг содержимое проекта, кроме:

- `.git`
- `.agents`
- старых архивов `.zip`
- локальных тестовых файлов, если они не нужны

Папка `uploads` должна остаться доступной на запись, если будут использоваться документы заявок.

## 2. База данных

Создайте базу MySQL/MariaDB в панели хостинга и импортируйте:

```text
monitoring_system.sql
```

Файл использует `utf8mb4`, поэтому база и таблицы должны быть в `utf8mb4_unicode_ci`.

## 3. Подключение к базе

Скопируйте файл:

```text
config/database.example.php
```

в:

```text
config/database.php
```

И пропишите реальные доступы:

```php
return [
    'host' => 'localhost',
    'dbname' => 'имя_базы',
    'user' => 'пользователь',
    'password' => 'пароль',
];
```

## 4. Первый админ

Если администратора еще нет, один раз откройте:

```text
/create_admin.php
```

Будет создан пользователь:

- логин: `admin`
- пароль: `admin123`

После первого входа смените пароль или удалите `create_admin.php` с хостинга.

## 5. Проверка перед выдачей пользователям

Проверьте короткий цикл:

1. Войти админом.
2. Создать пользователя с ролью `teacher`.
3. Добавить несколько ноутбуков.
4. Войти пользователем.
5. Подать заявку.
6. Одобрить заявку админом.
7. Выдать оборудование через QR.
8. Вернуть оборудование через QR.

Приоритет для первого выпуска: чтобы преподаватель понимал вход, подачу заявки, статус заявки и выход из системы. Админскую часть можно дополировать позже.
