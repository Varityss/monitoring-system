# Monitoring System

PHP/MySQL-система учета оборудования и заявок на выдачу. Проект рассчитан на обычный shared hosting без Node.js и без фреймворка.

## Возможности

- Авторизация пользователей с ролями `admin`, `teacher`/`user`.
- Учет оборудования: создание, редактирование, архив, поиск, импорт Excel.
- Уникальный штрихкод (`barcode`) для оборудования.
- Быстрый поиск оборудования сканером USB/HID.
- Создание заявок преподавателем.
- Выдача оборудования по заявке через сканирование.
- Возврат оборудования через сканирование.
- Журнал действий `activity_logs`.
- Dashboard администратора со сводкой.

## Локальный запуск

1. Скопируйте проект в папку веб-сервера, например:
   `C:\laragon\www\monitoring-system`
2. Создайте базу данных MySQL/MariaDB:
   `monitoring_system`
3. Импортируйте схему:
   `database/schema.sql`
4. Настройте подключение к БД в:
   `includes/db.php`
5. Проверьте базовый путь в:
   `config/app.php`

По умолчанию:

```php
define('BASE_URL', '/monitoring-system');
```

Если проект лежит в корне домена, замените на:

```php
define('BASE_URL', '');
```

## Обновление существующей базы

Перед обновлением сделайте резервную копию базы данных.

Для уже существующей базы импортируйте:

`database/migrations/final_update.sql`

Миграция добавляет:

- `equipment.barcode`;
- `equipment.updated_at`;
- `requests.admin_comment`;
- `requests.updated_at`;
- поля статуса выдачи/возврата в `request_equipment`;
- таблицу `activity_logs`;
- нужные индексы.

## Администратор

Если администратора еще нет, можно открыть:

`/monitoring-system/create_admin.php`

Будет создан пользователь:

- логин: `admin`
- пароль: `admin123`

После первого входа смените пароль или удалите `create_admin.php` с хостинга.

## USB-сканер штрихкодов

Обычный USB-сканер работает как клавиатура: вводит код в активное поле и отправляет Enter.

Где используется:

- `equipment/index.php` — быстрый поиск оборудования по штрихкоду, инвентарному или серийному номеру.
- `requests/view.php` — выдача оборудования по заявке через сканирование.
- `requests/return_scan.php` — возврат оборудования через сканирование.

Для проверки:

1. Создайте оборудование и заполните поле `Штрихкод`.
2. Откройте список оборудования.
3. Сканируйте код в поле `Сканировать штрихкод`.
4. При совпадении откроется карточка оборудования.

## Основные страницы

- `/index.php` — публичная главная.
- `/login.php` — вход.
- `/dashboard.php` — dashboard администратора.
- `/equipment/index.php` — оборудование.
- `/equipment/create.php` — добавление оборудования.
- `/equipment/import.php` — импорт Excel.
- `/requests/index.php` — заявки администратора.
- `/requests/return_scan.php` — возврат через сканер.
- `/teacher/index.php` — кабинет преподавателя.
- `/teacher/create_request.php` — создание заявки преподавателем.
- `/users/index.php` — пользователи.

## Проверка перед переносом на хостинг

- Импортирована актуальная схема или миграция.
- В `config/app.php` указан правильный `BASE_URL`.
- В `includes/db.php` указаны реальные данные подключения.
- PHP-версия поддерживает PDO MySQL.
- Папка `uploads/documents` доступна на запись, если используются акты.
